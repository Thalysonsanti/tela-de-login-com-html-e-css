# Login Interface – HTML & CSS

Projeto de **interface de autenticação (Login Page)** desenvolvido utilizando **HTML5 e CSS3**, com foco em construção de layout moderno, organização de formulários e estilização com efeito visual de transparência (*glassmorphism*).

A aplicação apresenta uma tela de login centralizada sobre imagem de fundo com campos de autenticação e links auxiliares.

## Preview

Interface contendo:

* Campo de **Email**
* Campo de **Senha**
* Link **Esqueci minha senha**
* Botão **Entrar**
* Link para **Cadastro**

O layout utiliza **blur e transparência** para criar um efeito visual moderno na interface.

## Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox

## Estrutura do projeto

```
login-page/
│
├── index.html
└── style.css
```

## Funcionalidades

* Estrutura de formulário de login
* Layout centralizado utilizando Flexbox
* Estilização moderna com efeito de **glassmorphism**
* Ícones de interface nos campos de input
* Interface limpa e focada em usabilidade

## Como executar o projeto

1. Clone o repositório

```
git clone https://github.com/seu-usuario/login-page.git
```

2. Acesse a pasta do projeto

```
cd login-page
```

3. Abra o arquivo no navegador

```
index.html
```

Ou utilize **Live Server no VS Code** para rodar localmente.

Este projeto foi desenvolvido com o objetivo de praticar:

* Estruturação de formulários com HTML
* Estilização de interfaces com CSS

* Organização de componentes visuais de autenticação
